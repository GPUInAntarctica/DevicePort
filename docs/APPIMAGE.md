# Linux AppImage / Linux AppImage 说明

`dist/DevicePort-x86_64.AppImage` is the recommended way to run DevicePort on a Linux
desktop. It bundles the fully static `deviceport` binary and a launcher.

## Double-click does nothing? Register it once

A freshly downloaded AppImage has no file-association on most desktops (GNOME in
particular), so double-clicking it appears to do nothing. Run the installer **once**:

```bash
bash packaging/install-linux.sh
```

It copies the AppImage to `~/.local/bin/`, installs an icon, generates a
`deviceport-gui` launcher and a `.desktop` entry, registers the AppImage MIME handler,
and — when writable — places a `DevicePort.desktop` launcher on your Desktop. After
that, double-click **DevicePort** (or any `.AppImage`) and a browser window opens with
the control panel — no terminal and no root required.

The launcher uses a self-contained demo network: it starts a local signaling server
on `127.0.0.1:19000` and a node with a userspace TUN, then opens
`http://127.0.0.1:9050`. This works with any AppImage version (it only needs the
bundled `deviceport` binary) and does not depend on FUSE-specific AppRun features.
To join a real network instead, use the command line below.

## Command-line usage

The AppImage passes arguments straight through to the bundled binary:

```bash
chmod +x DevicePort-x86_64.AppImage
./DevicePort-x86_64.AppImage server --listen '[::]:9000' --subnet 10.66.0.0/24
./DevicePort-x86_64.AppImage node --server '[::1]:9000' --name alice
./DevicePort-x86_64.AppImage version
./DevicePort-x86_64.AppImage            # interactive terminal menu
```

The AppImage needs FUSE to mount. If your system has no FUSE (or mounting is blocked),
run it extracted:

```bash
./DevicePort-x86_64.AppImage --appimage-extract-and-run
# or
APPIMAGE_EXTRACT_AND_RUN=1 ./DevicePort-x86_64.AppImage --launch-gui
```

## Build

```bash
# 1. build the static Linux binary
make build

# 2. build the AppImage (appimagetool path can be set with APPIMAGETOOL)
APPIMAGETOOL=/path/to/appimagetool-x86_64.AppImage make appimage

# 3. optional: register with the desktop (one time)
bash packaging/install-linux.sh
```

The AppDir sources live in `packaging/appimage/AppDir/`:

| Path | Purpose |
|------|---------|
| `AppRun` | launcher: no args = interactive terminal menu; other args pass through (the GUI launcher is generated by `install-linux.sh`) |
| `usr/bin/deviceport` | static release binary (copied by the build script) |
| `usr/share/applications/deviceport.desktop` | in-AppImage desktop entry (`Terminal=true` menu) |
| `usr/share/icons/hicolor/256x256/apps/deviceport.png` | icon |

## 中文

Linux 上推荐用 AppImage。刚下载的 AppImage 在多数桌面（尤其是 GNOME）没有文件关联，
**双击不会有反应**。先运行一次安装脚本注册：

```bash
bash packaging/install-linux.sh
```

之后双击桌面上的 **DevicePort** 图标，会打开浏览器显示控制面板，不需要终端、也不需要
root。脚本会在本机启动一个演示网络（本地服务器 + userspace TUN 节点）。
要加入真实网络请用命令行方式。

没有 FUSE 的环境可用 `--appimage-extract-and-run`。
